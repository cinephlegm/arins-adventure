# Asset provenance

The public source repository does not redistribute the original game's raw art, map images or audio.

## Identified third-party assets

### Mana Seed

Some environment art in the original project comes from the **Mana Seed** asset collection by **Seliel the Shaper**.

- Summer Forest: https://seliel-the-shaper.itch.io/
- Castle Dungeon: https://seliel-the-shaper.itch.io/

The original project contains a Tiled tileset named `seasonal sample (summer)` and dungeon art consistent with those Mana Seed packs. Raw Mana Seed files are intentionally kept out of the public repository.

### Turret sprites

The turret graphics match **Turret + Bullet Spritesheet Pixel Asset** by **spoonsweet**:

https://spoonsweet.itch.io/turret-bullet-spritesheet-pixel-asset

The original asset filenames and sizes match the source pack (`turret_BASE.png`, `turret_BULLET.png`, `turret_FACE.png`).

## Remaining assets

Player, NPC, UI, object and audio provenance is still being checked against the original 2024 project material. No claim of ownership or redistribution permission is made for unverified assets.

## Release builds

A public binary release containing third-party assets will only be published after the applicable asset licenses for the copies used in the 2024 project have been verified.
